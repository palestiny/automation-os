# Core Principles

1. Understand before coding.

2. Think before implementing.

3. Document every important decision.

4. Never use a Design Pattern without understanding the problem.

5. Every architecture decision has trade-offs.

6. Simplicity is preferred unless complexity solves a real future problem.

7. Refactoring is part of development.

8. Documentation is part of the product.

9. Code should explain WHAT.

Documentation should explain WHY.

10. Learning is more important than finishing quickly.
