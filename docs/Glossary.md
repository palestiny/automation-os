# Glossary

| Term | Meaning |
|---|---|
| Intent | Desired business objective |
| Workflow | Definition of work to be performed |
| Execution | Runtime attempt to execute a workflow |
| Capability | Business-meaningful ability exposed by the platform |
| Plugin | Replaceable implementation of a capability |
| Asset | Data/resource used or produced |
| Outcome | Meaningful result of execution |
| Orchestrator | Application-level execution coordinator |
| Registry | Component responsible for locating registered implementations |
| Dispatcher | Component responsible for routing/invoking capabilities |
| Adapter | Boundary translating an external technology into an internal contract |
| ADR | Architecture Decision Record |
| RFC | Request for Comments |
| DoD | Definition of Done |
