# Project Principles

This file is the compact daily reference for the project's governing principles.

## Product Principles

- AutoReel AI is an Automation Operating System.
- The product is not a YouTube downloader.
- The product is not a ChatGPT wrapper.
- The product is not a collection of scripts.
- AI is a replaceable capability.
- Execution is central.
- Capabilities should be replaceable and pluggable.
- Business outcomes matter more than individual technologies.

## Engineering Principles

- Domain first.
- Infrastructure second.
- Business before technology.
- Modular Monolith as the current architectural direction.
- Domain Driven Design.
- Clean Architecture thinking.
- SOLID.
- Testability first.
- Explicit architecture decisions.
- Documentation as part of delivery.

## Learning Principles

Every significant implementation should teach at least one professional engineering concept.

When a Design Pattern, architecture technique, Git operation, testing practice, or documentation practice is introduced, explain:

1. what it is;
2. why it exists;
3. why we need it here;
4. what problem it solves;
5. what trade-off it introduces.

## Daily Question

> Are we building the platform, or merely adding another script?

If the answer is unclear, stop and review the constitution and roadmap.
