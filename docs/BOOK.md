# AutoReel AI — Engineering Book

This is the long-form learning record of the project.

## How to Use It

The project should be understandable from its documentation without relying on memory of previous chat sessions.

The constitution explains the rules.

The charter explains the mission.

The roadmap explains where we are going.

The architecture documents explain how the system is organized.

ADRs explain important architectural decisions.

The learning documents explain what was learned.

The journal explains what happened and what comes next.

## Core Loop

Understand
→ Plan
→ Document
→ Implement
→ Test
→ Review
→ Commit
→ Reflect
→ Update Documentation
→ Continue
